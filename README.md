# Python for Geographic Data Science

Υλικό και notebooks για τη σειρά **Python για GIS και Γεωγραφική Επιστήμη Δεδομένων** του καναλιού **Αρχές Γεωπληροφορικής**.

Η σειρά ξεκινά από τα βασικά της Python και προχωρά σε:

- NumPy & Pandas
- καθαρισμό δεδομένων ΕΛΣΤΑΤ
- GeoPandas & Rasterio
- χωρική στατιστική
- PCA & clustering
- machine learning
- Geographic Data Science

## Περιβάλλον

Τα notebooks έχουν σχεδιαστεί για χρήση με **Positron + Jupyter + uv**.
