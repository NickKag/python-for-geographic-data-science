# Data Copyright and Redistribution Notes

## ELSTAT municipality boundaries — `DHMOI_2021.zip`

**Source:** Hellenic Statistical Authority (ELSTAT / ΕΛΣΤΑΤ), Cartography Department  
**Dataset:** Municipality boundaries for 2021 (`DHMOI_2021.zip`)  
**Course location:** `Data/course/vector/DHMOI_2021.zip`

### Repository policy

The file included in this repository is the **original, unmodified `DHMOI_2021.zip`** supplied by ELSTAT. It must remain unchanged when redistributed as part of this course repository.

Based on verbal guidance obtained from the **ELSTAT Cartography Department on 16 September 2026**, the original file may be uploaded/redistributed, while **modified or derivative versions of the cartographic data should not be publicly redistributed**.

Accordingly:

- `Data/course/vector/DHMOI_2021.zip` contains the original file only.
- Converted, enriched, clipped, reprojected, joined, or otherwise modified geometry datasets are **not committed to the public repository**.
- Course notebooks may create working or derived files locally during analysis. These should be written to a local folder such as `Data/processed/` and excluded from version control.
- Statistical attributes may be joined to the municipality geometries in memory or in local working files, but the resulting modified geospatial dataset should not be redistributed through this repository.
- ELSTAT should be credited as the source of the municipality boundary data wherever the dataset is used.
